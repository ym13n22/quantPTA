📈 均线交叉策略（含止损机制）

基于短期与长期均线交叉的量化交易策略，通过捕捉价格趋势变化生成买卖信号，并设有止损机制控制风险，适用于日频数据和波动性较大的市场（如期货）。

📌 策略简介

买入信号：短期均线（如5日）上穿长期均线（如40日）

卖出信号：短期均线下穿长期均线

止损机制：当累计收益低于设定阈值，强制平仓止损

⚙️ 核心指标

短期均线：近n日收盘价均值

长期均线：近m日收盘价均值

策略收益：收益 = 市场收益 × 持仓

止损判断：累计收益 < 止损阈值 → 清仓

💡 优化内容

持仓改进：采用position = allocation / open 动态控制仓位，便于组合投资

止损保护：限制最大回撤，防止资金大幅亏损

✅ 使用方法

安装依赖：

pip install pandas numpy matplotlib

运行策略回测：

python backtest.py
